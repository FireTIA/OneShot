# 🌟 Oneshot

**Oneshot** — написанный скрипт на python, который позволяет проверять WiFi сеть на уязвимость WPS. 
 - Ожидаемая версия: 0.0.60 BETA
 - Ожидаемая дата выхода: 2026.00 (Как нибудь потом)
***Скрипт был взят с Kali NetHunter***

---

## 🔧 Основные возможности данной ветки:

- **Изучение BETA кода**
- **Дать свои идеи перед выходом версии**
- **sudo pentyToster.py --Toster-pentester**
