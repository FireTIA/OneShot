# Settings

Этот файл описывает настройки OneShotPin by FireSoft.

---

## `OS_Target`

**Возможные значения:**

- `NetHunter`
- `Kali`
- кастомный путь, например `/home/firehost/OneShotPin_Log`

**Описание:**

Определяет, куда сохраняются итоговые файлы: логи и результаты проверки сетей.

- `NetHunter` → `/sdcard/nh_files/OneShotPin_Log`
- `Kali` → `/home/kali/OneShotPin_Log`
- любой другой непустой текст используется как кастомный путь без изменений

Если значение пустое или отсутствует, код может использовать безопасный fallback-путь.

---

## `Hide_Password_AP`

**Возможные значения:**

- `True`
- `Half`
- `False`

**Описание:**

Управляет тем, как пароль точки доступа отображается в терминале:

- `True` — полностью скрывать пароль.
- `Half` — показывать только часть пароля, остальное маскировать.
- `False` — показывать пароль полностью.

Важно: настройка влияет только на вывод в консоль. В лог-файл пароль записывается полностью.

## `Change_MAC_WlanX_Startup`

**Возможные значения:**

- `True` — псевдослучайный MAC с сохранением заводского OUI; используется `macchanger -a`.
- `True-r` — полностью случайный MAC, включая OUI; используется `macchanger -r`.
- `False` — не менять MAC-адрес.
- кастомный MAC, например `00:11:22:33:44:55`; используется `macchanger --mac=<ваш MAC>`.

**Описание:**

Определяет поведение модуля WlanX при старте скрипта. Если значение не равно `False`, перед запуском основной логики интерфейс временно выключается, применяется выбранная схема смены MAC, затем интерфейс снова включается.

## `Macchanger_Output_Mode`

**Возможные значения:**

- `raw`
- `pretty`

**Описание:**

Определяет формат вывода информации от macchanger:

- `raw` — показать сырой вывод macchanger.
- `pretty` — распарсить Current/Permanent/New и вывести в красивом формате.

---

## `Hello_banner`

**Возможные значения:**

- `default`
- `classic`
- `compact`
- `none`

**Описание:**

Определяет стиль приветственного баннера в начале работы скрипта:

- `default` — полный приветственный баннер: название, автор перевода, GitHub, версия и т.д.
- `classic` — укороченный баннер с основной информацией о скрипте.
- `compact` — компактный баннер в одну строку.
- `none` — не выводить приветственный баннер.

---

## `Check_Corp_AP_Action`

**Возможные значения:**

- `null`
- `yes`
- `ltx`
- `no`

**Описание:**

Определяет автоматическое действие, если рядом обнаружены потенциально корпоративные или управляемые точки доступа по OUI:

- `null` — спрашивать действие вручную каждый раз.
- `yes` — продолжать выполнение без изменений.
- `ltx` — пытаться занизить TX Power.
- `no` — завершать скрипт.

---

## `Check_Corp_AP_lTX_Value`

**Возможные значения:**

- `null`
- число от `1` до `30`

**Описание:**

Значение TX Power в dBm для действия `ltx`.

- `null` — спрашивать значение вручную.
- число `1-30` — использовать указанное значение автоматически.

Важно: фактическое изменение TX Power зависит от драйвера, чипсета, regulatory-настроек и поведения адаптера. Команда может выполниться без ошибки, но реальная мощность может остаться прежней.

---

## `Check_Corp_AP_Recheck_After_lTX`

**Возможные значения:**

- `null`
- `true`
- `false`

**Описание:**

Определяет, нужно ли повторно сканировать эфир после попытки занизить TX Power:

- `null` — спрашивать вручную.
- `true` — всегда повторять проверку.
- `false` — не повторять проверку.
